Impression double protocole (PDF / ZPL Natif)

Optimisation Zebra ZD421T : Ce module vous permet d'exporter soit un fichier PDF standard (traduit par le pilote de votre système d'exploitation), soit d'envoyer les étiquettes directement au serveur Linux en ZPL natif. Le format ZPL est recommandé pour les impressions de masse à haute vitesse.
